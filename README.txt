-------------------------------------------
Source installation information for modders
-------------------------------------------
This code follows the Minecraft Forge installation methodology. It will apply
some small patches to the vanilla MCP source code, giving you and it access 
to some of the data and functions you need to build a successful mod.

Note also that the patches are built against "unrenamed" MCP source code (aka
srgnames) - this means that you will not be able to read them directly against
normal code.

Source pack installation information:

Standalone source installation
==============================

To install this source code for development purposes, extract this zip file.
It ships with a demonstration mod. Run 'gradlew setupDevWorkspace' to create
a gradle environment primed with FML. Run 'gradlew eclipse' or 'gradlew idea' to
create an IDE workspace of your choice.
Refer to ForgeGradle for more information about the gradle environment
Note: On macs or linux you run the './gradlew.sh' instead of 'gradlew'

Forge source installation
=========================
MinecraftForge ships with this code and installs it as part of the forge
installation process, no further action is required on your part.

For reference this is version @MAJOR@.@MINOR@.@REV@.@BUILD@ of FML
for Minecraft version @MCVERSION@.

其实我觉得，各大MOD的机器的数据无非就这么几种，每一种可能有几个数值
1. 输入物品格。在工作过程中被消耗，可输入
2. 输出物品格，暂存产物的地方。细分可以分为主产物，副产物，或者按顺序第一、第二产物
3. 纯自由状态量，不可输入输出。如某些锅炉、反应堆的温度
4. 工作进程量，不可输入输出，一般单调递增，最多暂停或被重置。如烧练进程，产物处理进程
5. 可由外界输入，自身消耗的缓存。比如某些以液体为合成物的机器
6. 由自身产生，向外界输出的缓存。比如某些发电机的电力缓存
有GUI的各类机器基本上逃不出这6种，那么我们是否可以将原始NBT进行变量提取，提取出几个变量，直接写成变量名（英文）：值，然后让用户可以输入重命名，保存后直接写到配置文件中

路由器的功能：
路由器是一个网络的根节点，路由器可以连接升级方块，可以连接物品存储器、液体存储器、能量存储器，执行器取出的物品/方块/能量可以暂存在路由器连接的这些存储器当中，当存储器满了的时候就不能再输入，空了就不能再取出
执行器可以选择抽取到存储器，或从存储器中抽取，也可以直接转移到另一个执行器
存储器可以存储有限多种物品，相当于箱子的格，右键可以打开GUI，但是无法手动放入取出（鼠标操作禁用）只能通过管道/漏斗/本MOD功能/其他mod如AE2输入输出总线等操作。
存储器可以搭成多方块结构，与路由器用总线连接，总线是本MOD的一种连接线，只能用于连接存储器与路由器，以及存储器和接口
因为存储器可能需要和很多接口互动（如AE2的输入输出总线），如果你用的又是单方块存储器，有一个面还要和路由器相接，那么可以提供一个接口方块，用总线将其和存储器连接，管道/接口等就可以连接到接口，实现输入输出到存储器
液体存储器可以存储多种不同种类的液体，同样不能手动操作
路由器可以连接AP实现范围拓展，AP能够控制的距离也可以安装升级，耗电统一算在路由器上
路由器和所有与路由器连接的AP所能覆盖的总体空间算作整个网络的覆盖空间，路由器的最大连接数是这整个网络空间的最大连接数
每个路由器方块，最多可以同时连接16个设备，如果需要增加，可以把多个路由器方块贴在一起，外形要求是立方体形，不能有缺口，路由器任意方向长度不能超过8个
路由器在计算与其他方块距离的时候，遵循下东南定律，以下东南角的路由器方块为中心计算距离
路由器具有等级，等级决定了网络覆盖距离，每升一级都需要提高耗电量，存储器需要消耗路由器的电，也是连得越多耗电越多，但是和存储的东西多少无关
传感器和显示器不占用路由器频道，不增加路由器耗电量，只有执行器、AP，和带执行功能的其他设备占用频道，并增加耗电，存储器也不占用频道
路由器可以连接其他mod的能量管道/线缆等取得能量（RF/EU/gJ/ae）输入后在内部转为本mod的能量单位ie(internet energy)与RF一比一兑换，并无法输出
如果没有安装其他提供这些能量来源的mod，本mod提供一种"发电机"，把可以燃烧的物质放进去，可以产生能量，效率略低于RF系列的发电效率(鼓励玩家使用其他mod供能)
网络没进行一次操作，需要消耗一定的能量，消耗的能量多少取决于操作类型和转移的物品/液体/能量的数量，发出红石信号的操作不消耗能量，传输物品按照物品的个数消耗能量
液体按照液体的量消耗，采用"充值预消费"机制，即首先从能量来源抽取一定数量的能量存入路由器缓存，当累计传输液体达到规定值的时候清空缓存，并进行下一次能量抽取
传输物品/液体无损耗，传输能量有基础损耗20%，按距离增加，最多50%(所以除非无法布线只能使用本MOD无线传输能量，否则不推荐)，传输能量活动本身不耗能，传输的能量是原始单位，不转化成ie，也不能从一种能量转成另一种
